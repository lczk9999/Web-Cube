# Web-Cube

My website Web Cube, it is a web page that serves as a computer tab where there are some functions like calendar, stopwatch, search bar (very important). It is not connected to the web, it only serves to take you to three links: Google, YouTube and GitHub. In addition, there is a notepad where you can type and make your notes. That's it, but remembering that everything on the site is functional and further down there is more information about the code, descriptions and process of making the site/web page.


About the code, I used three, I separated it into three parts: an HTML file, another JavaScript and another in CSS. Each one was used to do something specific and perform a function.


HTML: In the HTML part I made its structure, I defined its beginning and it is in it that I make the initial background. I define and choose where each block will stay, its positioning, among other things with its texts, title and basically its initial interface. It can be said that without it the site would not work, because it is the main part of everything. About its process, it was easy, it was the part that took me the least time to make.


CSS: Now in CSS, it is as if it were the body of everything. It is in it that I give the characteristics and define things. Like the background in HTML I only say that there will be something and it is as if it were transparent, but in CSS I give the body indeed, the characteristics of the site, in this case the web. I choose the colors, details and buttons. About its process, it was the most annoying in my opinion, because I have a difficulty in choosing colors of things and making the design. I even admit that I used an AI to tell me the name of the colors, but I only used it to tell the name of the colors, everything was typed by me, but I arrived at an interesting result.



JavaScript: It is one of the most important parts, in it that I define the logic, it is the brain of everything. I define the logic of everything, how each button will work through conditions, definitions and variables, among other commands. It is a part that I already knew how to program pretty well, so I didn't have much difficulty making this part.


So this is a summary of the site and how it works. If you need more information, it is all available in the files that are in the code part of GitHub, in three different files.
